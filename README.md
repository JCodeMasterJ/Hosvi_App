## 🩺 Overview

**Hosvi_App** is an innovative hospital navigation platform designed to improve wayfinding for visually impaired users through a cross-platform Flutter application.  
It seamlessly combines geolocation, voice guidance, and geofencing to deliver an accessible and intuitive experience in healthcare environments.

### Why Hosvi_App?

This project aims to enhance accessibility and user experience in hospital navigation.  
The core features include:

- 🧭 **Navigation & Geofencing:** Precise location tracking and zone detection to guide users safely within hospital premises.  
- 🎙️ **Voice Guidance & Feedback:** Text-to-speech and haptic feedback to assist users with real-time audio cues.  
- 💻 **Cross-Platform Compatibility:** Support for Android, iOS, Web, Windows, Linux, and macOS, ensuring broad accessibility.  
- 🧩 **Developer-Centric Architecture:** Modular design, static analysis, and testing frameworks to facilitate customization and maintenance.  
- 🔗 **Backend Integration:** Firebase services and Google Maps Directions API for reliable data management and routing.
